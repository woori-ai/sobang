## 1. 건축관계법령

**건축법 vs 소방법**: 건축법은 **하드웨어**(마감재, 방화구획, 내화구조, 피난통로)를 다루고, 소방시설법은 **소프트웨어**(소화·경보·소화활동설비)를 다룹니다.

### 1-1. 용어
| 용어 | 뜻 | 함정 |
|---|---|---|
| 지하층 | 바닥에서 지표면까지 평균높이가 그 층 높이의 **1/2 이상** | |
| 주요구조부 | **내력벽·기둥·바닥·보·지붕틀·주계단** | 제외: 사이기둥, **최하층 바닥**, 작은 보, 차양, 옥외계단 |
| 신축 | 건축물이 없는 대지에 새로 | |
| 증축 | 건축면적·연면적·층수·높이를 **늘림** | |
| **개축** | 전부 또는 일부를 해체하고 **종전과 같은 규모**로 다시 | 학습평가 단골 |
| 재축 | **천재지변 등 재해로 멸실** → 다시 | |
| 이전 | 주요구조부를 해체하지 않고 같은 대지 안 다른 위치로 | |
| 대수선 | 내력벽·외벽 마감 **30 ㎡ 이상** 수선, 기둥·보·지붕틀 **3개 이상**, 방화벽·방화구획, 주계단·피난계단, 세대 간 경계벽 | |
| 도로 | 너비 **4 m 이상**. 대지는 도로에 **2 m 이상** 접해야 함 | 막다른 도로: 10 m 미만 2 m / 35 m 미만 3 m / 35 m 이상 6 m |
| 내화구조 | 화재 후 **재사용 가능**한 구조 (철근콘크리트·연와조) | 벽 철근콘크리트 **10 cm**, 벽돌조 **19 cm**, 기둥 지름 **25 cm 이상** |
| 방화구조 | 화염 확산을 막는 구조 (내화구조보다 약함) | 철망모르타르 **2 cm**, 석고판 + 모르타르 합계 **2.5 cm** |

### 1-2. 면적·높이·층수
| 항목 | 산정 기준 |
|---|---|
| 건축면적 | 외벽(기둥) **중심선**의 수평투영면적. 처마·차양 **1 m 이상** 돌출 시 끝에서 1 m 후퇴 (한옥 2 m, 축사 3 m, 전통사찰 4 m) |
| 건축면적 제외 | 지표면에서 **1 m 이하** 부분 (하역장 1.5 m), 보행·차량 통로, 지하주차장 경사로, 장애인 승강기 등 |
| 바닥면적 | 벽·기둥 **중심선** 수평투영면적. 노대는 길이 × **1.5 m** 공제, 필로티(통행·주차) 제외, 다락 층고 **1.5 m**(경사지붕 1.8 m) 이하 제외 |
| **연면적** | **각 층 바닥면적의 합계** (용적률 계산 때는 지하층·부속 주차장·피난안전구역 제외) |
| 건폐율 | 건축면적 ÷ 대지면적 × 100 |
| 용적률 | 연면적 ÷ 대지면적 × 100 |
| 높이 | 옥탑 등이 건축면적 **1/8 이하**면 **12 m 넘는 부분만** 산입 |
| 층수 | 지하층 제외, 옥탑 1/8 이하 제외. 구분이 불명확하면 **4 m마다 1층**. 부분마다 다르면 **가장 많은 층수** |

### 1-3. 피난시설
**직통계단 보행거리**
| 구분 | 보행거리 |
|---|---|
| 일반 | **30 m 이하** |
| 주요구조부 내화·불연 | **50 m 이하** (16층 이상 공동주택의 16층 이상 층은 **40 m**) |
| 반도체·디스플레이·이차전지 공장 + 자동식 소화설비 | **75 m** (무인화 공장 **100 m**) |

**피난계단 vs 특별피난계단**
| 구분 | 피난계단 | 특별피난계단 |
|---|---|---|
| 동선 | 옥내 → 계단실 → 피난층 | 옥내 → **노대 또는 부속실** → 계단실 → 피난층 |
| 설치 대상 | **5층 이상 또는 지하 2층 이하** 직통계단 | **11층 이상**(공동주택 16층) 또는 **지하 3층 이하** (바닥면적 400 ㎡ 미만 층 제외), 판매시설 1개소 이상 |
| 출입구 | 60분+ 또는 60분 방화문, 유효너비 **0.9 m 이상**, 피난 방향으로 열림 | 옥내→부속실: 60분+/60분 / 부속실→계단실: 60분+/60분/**30분** |
| 창문 | 다른 창문에서 **2 m 이상**, 내부 창은 망입유리 **1 ㎡ 이하** | 노대: 창문 **1 ㎡ 이상**, 부속실 **3 ㎡ 이상** (배연설비) |
| 공통 | 내화구조 구획, 실내 마감 **불연재료**, 예비전원 조명, 지상까지 직접 연결 | |

**옥상광장·기타**
| 항목 | 기준 |
|---|---|
| 옥상광장 난간 | **1.2 m 이상** |
| 피난용 옥상광장 | **5층 이상** 층이 공연장·종교집회장·게임시설(각 300 ㎡↑), 문화집회, 종교, 판매, 주점, 장례시설 |
| 헬리포트·대피공간 | **11층 이상 + 11층 이상 층 바닥면적 합 1만 ㎡ 이상**: 평지붕은 헬리포트, 경사지붕은 대피공간 |
| 대지 안 통로 | 단독주택 **0.9 m**, 500 ㎡ 이상 문화집회·의료·장례 등 **3 m**, 그 밖 **1.5 m** |
| 피난용승강기 | **고층건축물(30층 또는 120 m 이상)**에 1대 이상. 승강장 1대당 **6 ㎡ 이상**. 예비전원 초고층 **2시간**, 준초고층 **1시간** |

### 1-4. 방화구획·방화문
| 구분 | 기준 |
|---|---|
| 대상 | 주요구조부 내화·불연 + 연면적 **1,000 ㎡ 초과** |
| 10층 이하 | 바닥면적 **1,000 ㎡** 이내마다 |
| 11층 이상 | **200 ㎡** 이내마다 (벽·반자 불연 마감이면 **500 ㎡**) |
| 스프링클러 등 자동식 소화설비 | 위 면적의 **3배** |
| 층별 | **매층마다** (지하 1층→지상 직결 경사로 제외) |
| 자동방화셔터 | 방화문에서 **3 m 이내** 별도 설치. 불꽃·연기 감지 → **일부 폐쇄**, 열 감지 → **완전 폐쇄** |
| 관통부 틈새 | 내화채움구조 / 풍도: 방화댐퍼 |

| 방화문 | 성능 |
|---|---|
| **60분+** | 연기·불꽃 **60분** + 열 차단 **30분** |
| **60분** | 연기·불꽃 **60분** |
| **30분** | 연기·불꽃 **30분 이상 60분 미만** |

### 1-5. 방화시설
| 항목 | 기준 |
|---|---|
| 배연설비 대상 | **6층 이상** + 문화집회·판매·의료·업무·숙박·위락 등 / 층수 무관: 요양병원, 정신병원, 노인요양시설, 장애인 시설, 산후조리원 |
| 배연창 | 방화구획마다 1개 이상, 상변이 천장에서 **0.9 m 이내**, 유효면적 **1 ㎡ 이상** + 합계가 바닥면적의 **1/100 이상**, 감지기로 자동 열림 + 수동, 예비전원 |
| **소방관 진입창** | **2층 이상 11층 이하** 층마다 1개 이상, 벽면 **40 m**마다 추가, 역삼각형 **지름 20 cm** 붉은 표시, 타격지점 **지름 3 cm**, 폭 **90 cm 이상** × 높이 **1 m 이상**, 하단은 바닥에서 **80 cm 이내**(노대 난간이 있으면 120 cm), 유리 강화 **5 mm**·일반 **6 mm** 이하 |
| 내부 마감 | 거실 벽·반자: 불연·준불연·**난연** / 통로·계단: 불연·**준불연** |
| 외벽 마감 | 3층 이상 또는 9 m 이상 등: 불연·준불연 |
| 방화유리창 | 인접대지경계선에서 **1.5 m 이내** 창호 (스프링클러 헤드가 창에서 60 cm 이내면 제외) |

**피난·방화시설 금지행위 4가지**: ① 폐쇄·훼손 ② 주위에 물건 적치·장애물 설치 ③ 용도 장애·소방활동 지장 ④ 변경

## 2. 소방학개론

### 2-1. 연소
- 연소 3요소: **가연물 + 산소 + 점화원**. 4요소는 여기에 **연쇄반응**을 더한 것입니다.
- **표면연소(무염연소)**에는 연쇄반응이 없습니다. 그래서 **억제소화 효과가 없습니다**.

| 가연물 조건 (잘 타는 것) | 내용 |
|---|---|
| 산소 친화력 | **큼** |
| 활성화에너지 | **작음** |
| 열전도율 | **작음** (열이 쌓임). 단, 기체는 열전도율이 클수록 위험 |
| 연소열·비표면적·건조도 | **큼** |

- 불연성 물질: 불활성기체(He, Ne, Ar), 완전산화물(H₂O, CO₂), 흡열반응물질(N₂)
- 공기 중 산소 약 **21 vol%**, 한계산소지수(LOI) **14~15 vol%**
- 산화성 물질: 위험물 **제1류**(고체)·**제6류**(액체)

| 자연발화 원인 | 예 |
|---|---|
| 분해열 | 셀룰로이드, 니트로셀룰로오스 |
| 산화열 | 석탄, 건성유 |
| 발효열 | 퇴비 |
| 흡착열 | 목탄, 활성탄 |
| 중합열 | 시안화수소, 산화에틸렌 |
| 예방 | 통풍, 주위 온도·습도를 낮게 |

| 연소범위 (vol%) | | 연소범위 (vol%) | |
|---|---|---|---|
| 수소 | **4.1~75** | 메틸알코올 | 6~36 |
| 아세틸렌 | **2.5~81** (가장 넓음) | 암모니아 | 15~28 |
| 중유 | 1~5 | 아세톤 | 2.5~12.8 |
| 등유 | 0.7~5 | 휘발유 | 1.2~7.6 |

**연소 형태**
| 상태 | 형태 | 예 |
|---|---|---|
| 고체 | 분해연소 | 목재, 종이, 석탄 |
| | 증발연소 | **고체 파라핀(양초)**, 황, 열가소성수지 |
| | **표면연소** | **숯, 코크스, 마그네슘**, 목재 말기 |
| | 자기연소 | 제5류(자기반응성), 폭발성 물질 |
| 액체 | 증발연소 / 분해연소 | 대부분 / 글리세린, 중유 |
| 기체 | 확산연소 / 예혼합연소 | 황·적색 화염 / **청·백색**, 온도 높음 |

| 온도 | 정의 |
|---|---|
| **인화점** | 외부 에너지로 **착화 가능한 최저온도** (낮을수록 위험, 석유류 분류 기준) |
| 연소점 | 화염이 **5초 이상** 지속. 인화점보다 **5~10 ℃** 높음 |
| 발화점 | 외부 에너지 **없이** 착화. 황린 **35 ℃** |

### 2-2. 화재
| 등급 | 화재 | 특징 | 소화 |
|---|---|---|---|
| **A** | 일반 (면, 목재, 종이, 합성고분자) | 재가 남음, 발생 건수 가장 많음 | **냉각** (물) |
| **B** | 유류 (인화성 액체, 알코올, 인화성 가스) | 재 없음, 연소성 좋음 | **질식** (포). 알코올은 **내알코올형 포** |
| **C** | 전기 (통전 중) | 감전 위험 | 비전도성 약제 |
| **D** | 금속 (칼륨, 나트륨, 마그네슘, 알루미늄) | 분말상일 때 위험, 물과 반응해 **수소** 발생 | **수계 금지**, 금속화재용 분말·마른모래 |
| **K** | 주방 (식용유) | | **비누화 + 냉각** |

**실내화재 진행**
| 단계 | 외관 | 특징 |
|---|---|---|
| 초기 | **흰 연기** | 일부만 연소 |
| 성장기 | **검은 연기** 분출 | 천장까지 확대, 최성기 전초 |
| 최성기 | 연기 줄고 **화염 분출**, 유리 파손 | 복사열로 인접 건물 연소, 구조물 낙하 |
| 감쇠기 | 연기 **흑색 → 백색** | 연소 확산 위험 없음, 붕괴 위험 |

| 현상 | 핵심 |
|---|---|
| **플래시오버** (전실화재) | 복사열로 실내 가연물이 **일시에 발화**. 내화건물 출화 후 **5~10분** |
| **백드래프트** (연기폭발) | 문을 열 때 **신선한 공기가 유입**되어 폭발. 예방: 문 열기 전 **천장 개방(배연)** |
| **롤오버** (플레임오버) | **미연소가스**를 따라 천장면으로 파도처럼 확산 |

| 건물 | 최고온도 | 특징 |
|---|---|---|
| 목조 | **1,100~1,350 ℃** | **고온 단기형**. 출화→최성기 약 10분 |
| 내화조 | **800~1,050 ℃** | **저온 장기형**. 2~3시간 지속, 발연량 많음 |

| 열전달 | 특징 |
|---|---|
| 전도 | 직접 접촉 |
| 대류 | 유체 흐름 |
| **복사** | 열 이동에 **가장 크게** 작용, 인접 건물 연소의 주원인 |
| 비화 | 불티가 날아가 먼 곳에 발화 |

| 연기 속도 | |
|---|---|
| 수평 | **0.5~1 m/s** (사람 보행 1.0~1.2 m/s보다 **느림**) |
| 수직 (계단) | 초기 **2~3 m/s**, 농연 **3~5 m/s** |
| 복도 | 플래시오버 전 0.5, 후 0.75 m/s |

### 2-3. 소화
| 제거 요소 | 소화법 | 예 |
|---|---|---|
| 가연물 | **제거소화** | 가스밸브 잠금, 산림 벌목 |
| 산소 | **질식소화** | 포, CO₂, 모래 (LOI 이하로) |
| 열 | **냉각소화** | 물 (비열 **1 cal/g·℃**, 증발잠열 **539 cal/g**) |
| 연쇄반응 | **억제소화** | 분말, 할론 → **화학적** 소화 (나머지 셋은 물리적) |

- 알코올 화재는 물을 타서 농도를 **40% 이하**로 낮추면 꺼집니다(희석).
- 비수용성 유류 화재는 물을 세게 뿌려 **유화(에멀전)** 효과로 끕니다.

## 3. 위험물·전기·가스 안전관리

### 3-1. 위험물 류별
| 류 | 성질 | 핵심 |
|---|---|---|
| 1류 | **산화성 고체** | 가열·충격으로 분해되어 **산소 방출** |
| 2류 | **가연성 고체** | 저온 착화, 유독가스 |
| 3류 | **자연발화성·금수성** | **물과 반응**하거나 자연발화로 가연성 가스 |
| 4류 | **인화성 액체** | 증기가 **공기보다 무거움**, 물보다 가볍고 물에 녹지 않음 → 주수소화 대부분 불가 |
| 5류 | **자기반응성** | 산소를 품고 있어 **자기연소**, 연소속도가 매우 빠름 |
| 6류 | **산화성 액체** | 자체는 불연, 산소를 내 **조연성** |

**유류 취급 주의**: 난로 불을 끈 뒤 주유, 불붙은 채 이동 금지, 빈 드럼통 절단 전 유증기 완전 배출, 연료량 확인은 라이터가 아니라 **손전등**으로

### 3-2. 전기
| 원인 | 내용 |
|---|---|
| 단락(합선) | 피복 손상으로 직접 접촉 → 큰 전류·스파크·**용융흔** (1차: 외력·접촉불량, 2차: 화재 외부열) |
| 과부하 | 허용전류 초과. 이불·장롱 밑, **코드릴 감은 채** 사용, 꼬아 만든 전선 |
| **누전** | 3요건: **누전점·출화점(발화점)·접지점** |
| 기타 | 반단선, 트래킹·흑연화, 접촉불량(아산화동 증식), 정전기, 낙뢰 |

| 감전 방지 | 기준 |
|---|---|
| **누전차단기** | 감도전류 **30 mA 이하**, 동작시간 **0.03초 이하** (욕실 콘센트는 **15 mA**) |
| 기타 | 충전부 방호, 보호절연, 보호접지, 이중절연기기 |
| 예방 | 문어발 금지, **누전차단기 월 1~2회** 동작 확인, 비닐전선은 고열기구에 쓰지 않음(고무코드), KS 제품 |

### 3-3. 가스
| 구분 | **LPG** (액화석유가스) | **LNG** (액화천연가스) |
|---|---|---|
| 주성분 | 프로판(C₃H₈), 부탄(C₄H₁₀) | **메탄(CH₄)** |
| 용도 | 가정, 공업, 자동차 | **도시가스** |
| 비중 | **1.5~2** → 누출 시 **낮은 곳** | **0.6** → 누출 시 **천장** |
| 폭발범위 | 프로판 2.1~9.5%, 부탄 1.8~8.4% | **5~15%** |
| **누설경보기** | 연소기에서 수평 **4 m** 이내, 탐지기 **상단**이 **바닥에서 30 cm 이내** | 연소기에서 수평 **8 m** 이내, 탐지기 **하단**이 **천장에서 30 cm 이내** |

| 시점 | 주의 |
|---|---|
| 사용 전 | 냄새로 누설 확인·환기 (부취제 **메르캅탄**), 호스 밴드 확인 |
| 사용 중 | **파란 불꽃** 유지 (황색·적색은 불완전연소 → **CO**) |
| 사용 후 | 콕 + **중간밸브** 잠금. 장기 외출 시 용기밸브·메인밸브까지 |

## 4. 공사장 안전관리·화기취급 감독

### 4-1. 공사장
**임시소방시설 7종**: 소화기, 간이소화장치, 비상경보장치, 가스누설경보기, 간이피난유도선, 비상조명등, **방화포**

**화재위험작업**: 인화성·가연성·폭발성 물질 취급 / **용접·용단** / 전열기구 등 열 발생 / 알루미늄·마그네슘 **폭발성 부유분진** / 소방청장 고시 작업

| 공사장 화재 | 특징 |
|---|---|
| **전기화재** | 공사장 화재 원인 중 **가장 큰 비중**. 지하 수변전실·MCC실, 발화지점이 숨어 있어 초기대응이 늦음 |
| 방화 | 야간 보안 취약, 휘발유·시너 |
| 가설건축물 | 컨테이너 사무소는 **소방대상물이 아님** → 소방설비 의무 없음 |
| 작업자 부주의 | 용접 불티, 담뱃불, 고체연료 |
| 공정별 | 초기는 "연료지배형", 커튼월 이후 "연료지배형 + 환기지배형", **마감 공정(소방시설 정상작동 전)에 위험 최대** |

- 안전관리계획서는 **건설기술진흥법**에 따라 건설업자가 작성하고, 감리 확인 후 **착공 전 발주자**에게 냅니다.
- **비화기(cool-work)** 대체: 용접 → 기계적 볼팅, 납땜 → 나사·플랜지, 토치 절단 → 기계적 파이프 절단기
- 소화기를 든 **화재감시자**를 배치하고, 작업 종료 후 **최소 30분 이상** 감시합니다.

### 4-2. 화기취급작업
- 화기취급작업: **용접, 용단, 연마, 땜, 드릴** 등 불꽃을 내는 작업
- 근거 법령: 화재예방법 24조(소방안전관리자 업무 중 **"화기취급의 감독"**), 소방시설법 15조(임시소방시설), 산업안전보건기준 규칙 239~246조

| 숫자 | 기준 |
|---|---|
| **11 m** | 용접 불티 비산거리(실내 무풍). **화재감시자 배치 기준 반경** |
| **1,600 ℃** | 불티 온도 (발화온도 약 250~450 ℃) |
| 0.3~3 mm | 불티 직경 |
| 6,000 ℃ | 아크 최고온도 (보통 3,500~5,000 ℃) |
| **5 m** | 작업지점에서 소화기 비치 거리 |
| **30분** | 작업 종료 후 화재감시자 추가 상주 (이후 **3시간**까지 순찰) |
| 20 m | 신청서 1건당 범위: 층별, 같은 층에서 반경 20 m 초과마다 별도 신청 |
| 5분 | 밀폐공간: 전화하면 5분 안에 올 수 있는 곳에 구조팀 대기 |

**화재감시자를 배치해야 하는 곳**
1. 작업반경 **11 m 이내**에 가연성 물질이 있는 곳
2. 11 m 이내 바닥 아래쪽 가연물이 11 m 이상 떨어져 있지만 불꽃으로 쉽게 발화할 곳
3. 금속 칸막이·벽·천장 반대쪽 가연물이 **열전도·복사열**로 발화할 곳

**화기취급작업 절차**: **① 사전허가**(작업요청 → 허가서 발급) → **② 안전조치**(가연물 이동·보호, 소방시설 작동 확인, 장비 점검, 안전교육) → **③ 작업·감독**(화재감시자 입회, 상주 감시, 종료 확인)

- 화재감시자는 소방안전관리자, 보조자 또는 안전관리자가 지정한 인력입니다.
- 허가서는 **작업현장에 게시**하고 끝나면 **소방안전관리자에게 반납**합니다.
- 종료 후 확인: **불티 잔존(30분 후)**, 전원 차단, 인화성 물품 보관

| 재해 | 원인 | 대책 |
|---|---|---|
| 화재 | 불꽃 비산, 용접부 뒷면 가연물 | 불꽃받이·방염시트, 가연물 제거, 소화기 |
| 폭발 | 토치·호스 가스 누설, 드럼통 잔류 가스, **역화** | 누설 없는 호스, 내부 가스 확인, **역화방지기** |
| 화상 | 산소 누설, 산소를 공기 대신 환기에 사용 | 산소 위험성 교육 |
