## 1. 소화기구·자동소화장치

### 구성
- **분말소화기**
  - 가압식: 본체 안에 **가스용기(카트리지)**가 들어 있습니다. 생산이 중단됐고, 부식되면 파열 위험이 있어 **축압식으로 교체**해야 합니다.
  - 축압식: 약제와 질소를 함께 넣고 **지시압력계**로 압력을 확인합니다.
- **CO₂소화기**: 혼(노즐)·레버식 구조이고 안전밸브가 있습니다. **지시압력계가 없습니다.**
- **할론소화기**: 지시압력계가 있습니다. 단, 할론1301은 자체 증기압을 쓰므로 압력계가 없습니다.
- **간이소화용구**: 에어로졸식, 투척용(4개 이하 1세트), 소공간용, 마른모래 50L·팽창질석 80L(삽을 함께 비치, 0.5단위)
- **자동확산소화기**: 일반용(보일러실·건조실·세탁소·대량화기 취급소), 주방용, 전기설비용
- **자동소화장치 6종**: 주거용주방, 상업용주방, 캐비닛형, 가스, 분말, 고체에어로졸

### 수치
| 항목 | 기준 |
|---|---|
| 대형소화기 | 능력단위 **A 10 이상, B 20 이상** (소형은 1단위 이상, 대형 미만) |
| 축압식 정상 압력 | **0.7~0.98 MPa (녹색)**. 황색은 저압, 적색은 과압 |
| 내용연수 (분말) | **10년**. 성능확인에 합격하면 10년 미만은 3년, 10년 이상은 1년 연장 |
| CO₂ 무게 판정 | 손실량이 **약제중량의 5 %를 넘으면 불량** (분모는 총중량이 아니라 약제중량) |
| 보행거리 | 소형 **20 m**, 대형 **30 m** 이내 |
| 설치 높이 | 바닥에서 **1.5 m 이하** |
| 구획 거실 | **33 ㎡ 이상**으로 구획된 거실마다 추가 |
| 간이소화용구 | 전체 능력단위의 **1/2 이하**만 인정 (노유자시설 제외) |
| 능력단위 1단위당 바닥면적 | 위락 **30 ㎡** / 공연장·집회장·관람장·문화재·장례식장·의료시설 **50 ㎡** / 근생·판매·숙박·노유자·업무·공장·창고·공동주택 등 **100 ㎡** / 그 밖 **200 ㎡** |
| 완화 | 주요구조부 내화 + 실내 불연·준불연·난연 마감이면 위 면적 **×2** |
| 부속용도 추가 | 보일러실·건조실·세탁소·주방 등은 **25 ㎡마다 1단위**(주방은 **K급 1개 이상**). 발전실·변전실·전산실은 **50 ㎡마다** 적응성 소화기 1개 |
| 공동주택 (NFTC 608) | **100 ㎡마다 1단위**, 각 세대와 공용부(승강장·복도)마다 |
| 가스누설 탐지부 | **LNG**(공기보다 가벼움)는 **천장 30 cm 이하**, **LPG**(무거움)는 **바닥 30 cm 이하** |

### 작동 원리·약제
| 약제 | 적응 화재 | 소화효과 |
|---|---|---|
| 제1인산암모늄 (NH₄H₂PO₄) | **ABC** | 질식·냉각·부촉매 |
| 탄산수소나트륨 / 탄산수소칼륨 / 탄산수소칼륨+요소 | BC | 질식·부촉매 |
| CO₂ (순도 99.5 %) | BC | **질식·냉각** |
| 할론 | ABC (종류별) | **억제(부촉매)** + 질식 |

- 화재 분류: **A 일반, B 유류, C 전기, D 금속, K 주방**
- C·D·K급은 능력단위를 지정하지 않습니다.

### 점검
1. 외형: 본체 부식(가압식이면 교체), 손잡이·레버·누름쇠 변형, 호스·혼·노즐 막힘·파손
2. 지시압력계: 바늘이 **녹색 범위**에 있는지 확인
3. 약제: 흔들어서 굳었는지 확인
4. 안전핀 체결 상태
5. CO₂소화기: 무게를 측정해 제원표와 비교
6. 자동확산소화기: 압력계가 녹색인지 확인

### 이상 원인 → 조치
| 증상 | 원인 | 조치 |
|---|---|---|
| 압력계 황색(저압) | 가스 누설 | 재충전·교체 |
| 압력계 적색(과압) | 과충전 | 교체 |
| 약제가 굳음 | 습기 | 교체 |
| 가압식 본체 부식 | 노후 | **축압식으로 교체** |

### 셀프 체크
<details><summary>Q. CO₂소화기는 왜 무게로 점검하나?</summary>
지시압력계가 없기 때문입니다. 제원표 총중량에서 측정 무게를 뺀 손실량이 약제중량의 5 %를 넘으면 불량입니다.</details>

<details><summary>Q. 위락시설 600 ㎡, 내화구조 + 불연재 마감일 때 필요한 능력단위는?</summary>
30 ㎡ × 2 = 60 ㎡당 1단위이므로 600 ÷ 60 = <b>10단위</b>입니다.</details>

## 2. 옥내·옥외소화전 + 펌프

### 구성 (물이 흐르는 순서)
**수원** → (풋밸브) → **흡입배관**(연성계·진공계) → **펌프** → 토출측 **체크밸브** → **개폐표시형밸브** → 배관 → **소화전함**(방수구·호스·관창)

펌프 주변에 붙는 장치는 다음과 같습니다.

| 장치 | 역할 | 함정 포인트 |
|---|---|---|
| **압력챔버** (기동용 수압개폐장치) | 압력이 떨어지면 펌프를 자동으로 기동·정지시키고, 급격한 압력 변화를 완충합니다 | 용량 **100 L 이상**. 안전밸브·배수밸브·압력스위치·압력계가 붙음 |
| **전자식 기동용 압력스위치** | 1개로 펌프 2~3대를 제어 | |
| **풋밸브** | 수원이 펌프보다 낮을 때 여과 + 역류 방지(체크) | |
| **물올림장치** | 흡입배관에 물을 채워 둠 | **수원이 펌프보다 낮을 때만** 필요 |
| **순환배관 + 릴리프밸브** | 체절운전 중 수온 상승 방지 | 체크밸브 **이전**에서 분기, **20 mm 이상**. 릴리프밸브는 **체절압력 미만**에서 개방 |
| **성능시험배관** | 펌프 성능 확인 | 토출측 개폐밸브 이전에서 분기, 유량계 앞 개폐밸브·뒤 유량조절밸브 |
| **개폐표시형밸브** | OS&Y(스템이 올라오면 개방), 버터플라이 | 버터플라이는 마찰손실 때문에 **흡입측에 설치 불가** |
| **체크밸브** | 스모렌스키(리프트형, 수격 방지)는 펌프 토출측·송수구에, 스윙형은 유량이 적은 곳에 | |
| **동력제어반(MCC)** | 펌프 전원·기동 (앞면 **적색**) | 평상시 **자동** |
| **감시제어반** | 펌프·비상전원·수조 수위 감시 | 평상시 **자동(연동)**. 펌프압력스위치·저수위 표시등이 **꺼져 있어야** 정상 |

가압송수 방식: 펌프 / 고가수조(자연낙차) / 압력수조(압축공기) / 가압수조(압축공기·불연성 고압기체, **전원 불필요**)

### 수치 — 옥내 vs 옥외
| 항목 | 옥내소화전 | 옥외소화전 |
|---|---|---|
| 방수량 | **130 L/min** | **350 L/min** |
| 방수압 | **0.17~0.7 MPa** | **0.25~0.7 MPa** |
| 동시 개수 N | 최대 **2개** (고층건축물은 5개) | 최대 **2개** |
| 수원 | N × **2.6 ㎥** (130 L × 20분) | N × **7 ㎥** (350 L × 20분) |
| 고층 수원 | 30~49층 N × **5.2 ㎥**(40분), 50층 이상 N × **7.8 ㎥**(60분) | — |
| 거리 | 방수구까지 **수평거리 25 m** | 소화전까지 **수평거리 40 m** |
| 방수구 높이 | 바닥에서 **1.5 m 이하** | — |
| 호스 | **40 mm** (호스릴 25 mm) | **65 mm** |
| 노즐 구경 (방수량 계산) | 13 mm | 19 mm |
| 소화전함 | 함 위에 위치표시등, 표면에 "소화전" | 소화전에서 **5 m 이내**. 10개 이하는 소화전마다, 11~30개는 11개 이상 분산, 31개 이상은 3개마다 1개 |

- 고층건축물: **30층 이상 또는 120 m 이상**
- 방수량 공식: **Q = 2.065 × D² × √P** (D는 mm, P는 MPa). 피토게이지는 노즐 선단에서 **D/2** 떨어진 곳에 댑니다.
- 창고 (NFTC 609): 수원 N × **5.2 ㎥**, 비상전원 **40분**

### 작동 원리
방수구 개방 → 배관 압력 저하 → 압력챔버 압력스위치 작동 → **충압펌프가 먼저** 기동 → 계속 떨어지면 **주펌프** 기동 → 방수

| 압력스위치 세팅 | 기준 |
|---|---|
| RANGE | **정지압력** |
| DIFF | 정지압력 − 기동압력 (**기동 = RANGE − DIFF**) |
| 주펌프 기동점 | 자연낙차압 + K (옥내 **0.22**, SP **0.15** MPa) |
| 충압펌프 기동점 | 주펌프 기동점 + **0.05~0.1 MPa** |
| 주펌프 정지 | 자동 정지 안 함. **수동 정지** (2006.12.30 이후 건축허가 대상) |

### 점검 ① 펌프 성능시험
| 단계 | ① 토출측 개폐밸브 | ② 성능시험배관 개폐밸브 | ③ 유량조절밸브 | 합격 기준 |
|---|---|---|---|---|
| 준비 | **폐쇄** | 폐쇄 | 폐쇄 | 감시제어반 **정지**, 동력제어반 **수동** |
| 체절운전 | 폐쇄 | **폐쇄** | **폐쇄** | 토출량 0에서 압력이 정격의 **140 % 이하**. 릴리프밸브가 **체절압력 미만**에서 열림 |
| 정격부하운전 | 폐쇄 | **완전 개방** | 서서히 개방 | 유량 **100 %**에서 정격압력 **이상** |
| 최대운전 | 폐쇄 | 개방 | **더 개방** | 유량 **150 %**에서 정격압력의 **65 % 이상** |
| 복구 | **개방** | 폐쇄 | 폐쇄 | **충압펌프 → 주펌프** 순서로 자동 복귀 |

주의 사항
- 유량계에 기포가 지나가면 안 됩니다. 흡입배관 공기 유입, 풋밸브와 수면이 너무 가까움, 공동현상을 의심합니다.
- 밸브를 급하게 여닫으면 수격이 생깁니다.
- 배수 처리를 미리 확인합니다(집수정 배수펌프 용량이 작을 수 있음).

### 점검 ② 방수압력 측정
2개(1개뿐이면 1개)를 동시에 개방 → 직사형 관창으로 봉상주수 → 피토게이지를 노즐 선단에 직각으로 D/2 거리에 댐 → 0.17~0.7 MPa 확인

### 이상 원인 → 조치
| 증상 | 원인 | 조치 |
|---|---|---|
| 흡입배관에 물이 없음, 물올림탱크 배수가 잦음 | **풋밸브 고장** | 풋밸브 수리·교체 |
| 성능시험 때 릴리프밸브가 안 열림 | 세팅압력 불량, 기구 불량 | 재조정·교체 |
| 압력이 떨어지면 주펌프가 먼저 기동 | **압력스위치 조정 불량** | 재조정 |
| 배관 압력이 수시로 떨어져 충압펌프가 자주 기동 | **체크밸브 밀림 또는 누수** | 토출측·송수구측·옥상수조 체크밸브 교체, 누수 보수 |
| 방수가 안 됨 | 펌프 기동 불량, 제어반이 자동 상태가 아님 | 제어반 자동 전환 |
| 펌프는 정상인데 방수가 안 됨 | **제수변(개폐밸브) 미개방** | 밸브 개방 |
| 기동표시등이 안 켜짐 | 기구 불량, 선로 단선 | 교체·보수 |
| (압력스위치) 압력이 내려가지 않아 기동 불능 | **물기둥효과**: 자연낙차압보다 기동점을 낮게 세팅 | 기동점을 자연낙차압 + K로 |

### 셀프 체크
<details><summary>Q. 정격 400 L/min·80 m 펌프의 체절압력 한도와 150 % 운전 기준은?</summary>
정격 0.8 MPa × 1.4 = <b>1.12 MPa 이하</b>, 600 L/min에서 0.8 × 0.65 = <b>0.52 MPa 이상</b>입니다.</details>

<details><summary>Q. RANGE 0.7, DIFF 0.2일 때 기동·정지 압력은?</summary>
정지 <b>0.7 MPa</b>, 기동 0.7 − 0.2 = <b>0.5 MPa</b>입니다.</details>

## 3. 스프링클러

### 구성
헤드, 수원, 가압송수장치, 배관(**가지배관**·**교차배관**), 유수검지장치(알람밸브 등), 음향·기동장치, 송수구

- **헤드**: 프레임 + 반사판(디플렉터) + 감열체(퓨즈블링크 또는 유리벌브). 폐쇄형과 개방형이 있습니다.
- **가지배관**: **토너먼트 방식 금지**(마찰손실·수격), 한쪽 가지배관에 헤드 **8개 이하**
- **교차배관**: 가지배관과 수평이거나 그 밑에 설치. 끝에 청소구와 나사식 캡

### 수치

### 작동 원리 — 5방식 비교
| 방식 | 1차측 | 2차측 | 헤드 | 밸브 | 작동 순서 | 장점 / 단점 |
|---|---|---|---|---|---|---|
| **습식** | 가압수 | **가압수** | 폐쇄형 | 알람밸브 | 헤드 개방 → 2차 압력 저하 → 클래퍼 개방 → 압력스위치(사이렌·화재표시등·밸브개방표시등) → 펌프 기동 | 구조 간단·저렴·신속 / **동결 우려**, 오작동 시 수손 |
| **건식** | 가압수 | **압축공기·질소** | 폐쇄형 | 건식밸브 + **급속개방기구(엑셀러레이터·익저스터)** | 헤드 개방 → 공기압 저하 → 클래퍼 개방 → 방수 | 동결 지역·옥외 가능 / 살수 지연, 압축공기가 연소 촉진 |
| **준비작동식** | 가압수 | **대기압** | 폐쇄형 | 프리액션밸브 | 감지기 **A and B** → 전자밸브 → 중간챔버 감압 → 밸브 개방 → 2차측 급수 → 헤드 개방 → 방수 | 동결 가능, 오작동 수손 없음 / 감지기 별도, 구조 복잡 |
| **부압식** | 가압수 | **부압 (진공)** | 폐쇄형 | 준비작동식 + 진공펌프 | 오작동하면 진공으로 물을 빨아들임 | 배관 파손·오작동 수손 방지 |
| **일제살수식** | 가압수 | **대기압** | **개방형** | 일제개방밸브(델류지) | 감지기 A and B → 전자밸브 → 밸브 개방 → **구역 전체 방수** | 초기화재 신속·층고 높은 곳 / 대량 수손 |

- 교차회로: 감지기 **A or B → 경보만** 울립니다. **A and B**가 모두 작동해야 밸브가 열립니다.
- 오경보 방지: 구형은 **리타딩챔버**, 신형은 압력스위치 내부 **지연회로(4~7초)**

### 점검 ① 습식
1. 사전 통보, 수신반 경보스위치 정지(필요하면 잠시 정상)
2. **시험밸브(말단시험밸브) 개방** → 2차측 압력 저하 → 클래퍼 개방 → 지연 후 압력스위치 작동
3. 확인: 감시제어반 화재표시등·밸브개방표시등, 사이렌, 펌프 자동 기동
4. 복구: 시험밸브 잠금 → 클래퍼 자동 복구. 충압펌프는 자동 정지, **주펌프는 수동 정지**

### 점검 ② 준비작동식
- 준비: **2차측 개폐밸브 폐쇄**, 배수밸브 개방 (2차측으로 물이 나가지 않게)
- 작동 방법 5가지
  1. 감지기 2개 회로 작동
  2. SVP(수동조작함) 수동조작스위치
  3. 밸브의 수동기동밸브 개방
  4. 감시제어반 수동기동스위치
  5. 동작시험스위치 + 회로선택스위치(2회로)
- 밸브 부품 번호(그림 문제 단골): ① 1차 개폐밸브 ② 2차 개폐밸브 ③ **세팅밸브** ④ 1차 압력계 ⑤ 2차 압력계 ⑥ 경보시험밸브 ⑦ **압력스위치** ⑧ 배수밸브 ⑨ **전자밸브** ⑩ 수동기동밸브
- 복구 순서
  1. 1차 개폐밸브 폐쇄 → 펌프 정지
  2. 제어반 복구 (수동식이면 전자밸브도 복구)
  3. 배수밸브 폐쇄
  4. **세팅밸브 개방** → 중간챔버에 급수
  5. 1차 압력계가 오르면 1차 개폐밸브를 서서히 개방
  6. 2차 압력계가 **오르지 않으면 정상** (오르면 배수부터 다시)
  7. 세팅밸브 폐쇄
  8. 2차 개폐밸브를 서서히 개방
  9. 제어반을 자동으로

### 이상 원인 → 조치
| 증상 | 원인 | 조치 |
|---|---|---|
| 비화재 시 사이렌 (습식) | 순간 압력 변동 | 리타딩챔버·지연회로 확인 |
| 복구 후 2차 압력계 상승 (준비작동) | 클래퍼가 제대로 안착하지 않음 | 배수 후 세팅 반복 |
| 동결 파손 (습식) | 난방 안 되는 장소 | 건식·준비작동식 적용 |
| 주방·보일러실 헤드 오작동 | 표시온도 부적합 | 주위온도에 맞는 표시온도로 |

### 셀프 체크
<details><summary>Q. 2차측이 "대기압"인 방식 두 가지는?</summary>
<b>준비작동식</b>(폐쇄형 헤드)과 <b>일제살수식</b>(개방형 헤드)입니다.</details>

<details><summary>Q. 준비작동식에서 A 감지기만 작동하면?</summary>
화재표시등·지구표시등 점등과 경보만 울리고, <b>밸브는 열리지 않습니다</b>.</details>

## 4. 가스계 소화설비

### 구성
**기동용기**(+ **솔레노이드밸브**) → 동관 → **저장용기** → 집합관 → **선택밸브** → 배관 → **분사헤드**
- 부속: 압력스위치(선택밸브 2차측), 방출표시등(출입문 위), 수동조작함(기동스위치·**방출지연스위치**·전원표시등)

| 부품 | 역할 |
|---|---|
| 솔레노이드밸브 | 전기 신호를 받으면 파괴침이 기동용기 봉판을 뚫습니다. 수동조작버튼이 있음(안전클립 제거 후 누르면 **즉시 격발**) |
| 선택밸브 | 방호구역이 2곳 이상일 때 저장용기를 함께 쓰고, 해당 구역으로 보냄 |
| 압력스위치 | 약제 **방출 압력**으로 작동 → 방출표시등 점등 |
| 방출지연스위치 | 자동복귀형. 누르고 있는 동안 타이머를 순간 정지 |

방출방식: 전역방출(밀폐 방호구역) / 국소방출(화점에 직접) / 호스릴(이동식)

### 수치·약제
| 약제 | 소화효과 | 특징 |
|---|---|---|
| CO₂ | **질식·냉각** | 심부화재 적합, 진화 후 깨끗, 비전도성 / **질식 위험**, 방사 시 동상·소음 |
| 할론 | **억제(연쇄반응 차단)** + 질식·냉각 | |
| 할로겐화합물 및 불활성기체 | 할론 대체 | |

- 지연시간: 경보 후 약 **30초** (이 시간 안에 대피)

### 작동 순서
감지기 A·B 작동(자동) 또는 수동조작함 버튼(수동) → 수신기 → 경보(사이렌)·자동폐쇄장치·환기팬 정지 → **지연(30초)** → **솔레노이드** 작동 → **기동용기** 개방 → 기동가스가 **선택밸브·저장용기** 개방 → 약제 방출 → **압력스위치** 작동 → **방출표시등** 점등

> 함정: 방출표시등은 약제가 **실제로 방출된 뒤** 켜집니다.

### 점검
**점검 전 안전조치 (순서 출제)**
1. 기동용기 → 선택밸브 **조작동관 분리**, 기동용기 → 저장용기 **개방용 동관 분리**
2. 제어반의 솔레노이드 **연동 정지**
3. **안전핀 체결 → 솔레노이드 분리 → 안전핀 제거** (격발 준비)

**격발시험 4가지** (모두 연동 전환 후)
1. 솔레노이드 수동조작버튼
2. 수동조작함 기동스위치
3. 교차회로 감지기 A·B 작동
4. 제어반 수동조작스위치

**방출표시등 시험**: 압력스위치 테스트 버튼을 당김 → 출입문 위 방출표시등, 수동조작함 방출등, 제어반 방출표시등 점등 확인 → 다시 눌러 복구

**복구 순서**
1. 제어반 복구스위치
2. 솔레노이드 연동 정지
3. 격발된 솔레노이드 복구
4. 안전핀 체결 후 기동용기에 결합
5. 연동 상태를 확인한 뒤 안전핀 분리
6. 분리했던 조작동관 결합

### 이상 원인 → 조치 (CO₂ 질식사고, p.94~95)
| 원인 | 예방 |
|---|---|
| 작업 전 점검을 확인하지 않음 | 수동 전환(연동 정지)·솔레노이드·동관을 분리한 뒤 작업 |
| 자동 상태에서 작업 | 감독자 배치, 출입금지 표지 |
| 경보를 무시하거나 스위치를 끔 | 경보 후 **30초 안에 대피** |
| 안전교육 미실시, 복구 전 정보전달 미흡 | 교육, 공기호흡기 비치, **환기 전 진입 금지** |

### 셀프 체크
<details><summary>Q. 솔레노이드 안전조치 3단계 순서는?</summary>
<b>안전핀 체결 → 솔레노이드 분리 → 안전핀 제거</b>입니다.</details>

## 5. 경보설비 (자탐·수신기·비상방송)

### 구성
**감지기·발신기** → (중계기) → **수신기** → 음향장치(주경종·지구경종)·표시등·시각경보기 / 비상방송 연동

| 구분 | P형 | R형 |
|---|---|---|
| 신호 | 회로별 공통신호 (실선) | 중계기를 거친 **고유신호(통신)** |
| 표시 | 회로별 **지구표시등** | LCD 모니터, 그래픽 표시판 |
| 용도 | 중소형 건물 | **대형 건물** (배선 수 감소) |
| 기록장치 | — | **999개 이상** 저장, 넘으면 오래된 것부터 자동 삭제, 임의 수정·삭제 불가 |

### 수치
| 항목 | 기준 |
|---|---|
| 경계구역 | 2개 건축물·2개 층에 걸치지 않음(500 ㎡ 이하면 2개 층 가능), **600 ㎡ 이하·한 변 50 m 이하** (내부가 다 보이면 1,000 ㎡ 이하) |
| 수신기 조작스위치 / 발신기 높이 | **0.8~1.5 m** |
| 발신기 | 층마다, **수평거리 25 m 이하** |
| 지구음향장치 | 층마다 수평거리 **25 m 이하**, 1 m 떨어진 곳에서 **90 dB 이상** |
| 시각경보기 | 바닥에서 **2~2.5 m** (천장이 2 m 이하면 천장에서 0.15 m 이내) |
| 비상방송 스피커 | 실내 **1 W** 이상, 실외·일반 **3 W** 이상, 수평거리 25 m 이하 |
| 비상방송 개시 | 화재 신고 후 **10초 이하** |
| 비상방송 음량조정기 | **3선식** 배선 |

**경보방식 (11층 이상, 공동주택은 16층 이상 = 우선경보)**
| 발화층 | 경보 범위 |
|---|---|
| 2층 이상 | 발화층 + **직상 4개 층** |
| 1층 | 발화층 + 직상 4개 층 + **지하층** |
| 지하층 | 발화층 + 직상층 + **기타 지하층** |

**감지기 설치유효면적 (㎡)**

### 작동 원리
| 감지기 | 원리 | 설치 장소 |
|---|---|---|
| 차동식 스포트형 | 온도 **상승률**. 감열실 공기 팽창 → 다이아프램 → 접점 | 거실, 사무실 |
| 정온식 스포트형 | 일정 **온도** 이상. **바이메탈**이 휨 | **보일러실, 주방** |

- 배선: **송배선식**(도통시험이 가능하도록). 병렬식은 불량입니다.

### 점검 — P형 수신기 3대 시험
| 시험 | 목적 | 순서 (로터리 방식) | 판정 |
|---|---|---|---|
| **동작시험** | 수신기가 화재신호를 정상 처리하는지 | **① 동작시험 → ② 자동복구 → ③ 회로시험 돌림** / 복구: **③ 회로시험 정상위치 → ① → ②** | 화재표시등·지구표시등 점등, 음향 작동. 1회선마다 복구하며 전 회선 시험 (축적형은 **비축적** 위치) |
| **도통시험** | 감지기 회로 **단선** 여부 | 도통시험스위치 → 회로시험스위치 회전 / 복구: 회로시험 정상위치 → 도통시험 복구 | 전압계 **4~8 V 정상, 0 V 단선** / 확인등 녹색 정상, 적색 단선 |
| **예비전원시험** | 정전 시 자동 절환, 전압 | 예비전원시험스위치를 **누르고 있는 동안**만 | 전압계 **19~29 V**, 램프 녹색 정상. "28 V 높음 / 24 V 정상 / 20 V 낮음" |

- 오작동방지기(축적): 점검할 때는 **비축적**, 평상시는 **축적**
- 시험 후 모든 스위치를 정상위치로 돌려 **스위치주의등이 꺼졌는지** 확인합니다.

**감지기 점검**
1. 감지기 시험기·연기 스프레이로 작동 → LED가 켜지면 정상
2. 안 켜지면 회로 전압 측정: **정격전압 80 % 이상이면 감지기 불량(교체), 0 V면 회로 단선(보수)**

**발신기 점검**: 작동스위치 누름 → 발신기 작동표시등·수신기 응답표시등 점등, 경종·방송 연동 확인 → 스위치 복구 → 수신기 복구

- 2선식: 평상시 **켜져 있으면 정상**, 꺼져 있으면 비정상
- 예비전원: 점검스위치를 당기거나 눌러 자동 절환·점등 확인. **예비전원감시등이 꺼져 있어야 정상**

### 작동 원리 — 부속실 제연
화재 → 감지기 작동(또는 수동기동) → 화재경보 → **급기댐퍼 개방** → 댐퍼가 완전히 열린 뒤 **송풍기 작동** → 계단실·부속실로 송풍 → 설정압력을 넘으면 **플랩댐퍼**가 과압 배출

- 차압은 화재 때가 아니라 **평상시 개념**입니다.
- 거실제연은 **수평**피난, 부속실 급기가압은 **수직**피난을 돕습니다.

### 점검 — 부속실 제연
1. 옥내 감지기 작동(또는 수동기동스위치)
2. 화재경보·댐퍼 개방 확인
3. 송풍기 작동, 계단실·부속실 바람 확인
4. 문을 닫고 부속실 안에서 **차압 측정 (40 Pa 이상)**
5. 문을 열고 풍속계로 **방연풍속 측정**
6. 과압배출장치 작동 확인
7. 수신기 복구

### 이상 원인
| 증상 | 원인 |
|---|---|
| 출입문이 안 열림 | 차압 과다 (개방력 110 N 초과) → 과압배출장치 확인 |
| 연기가 계단으로 유입 | 차압·방연풍속 부족, 자동폐쇄장치 불량 |

### 셀프 체크
<details><summary>Q. 연면적 30,000 ㎡ (1·2층 합 10,000 ㎡) 건물의 저수량과 채수구 수는?</summary>
1·2층 합이 15,000 ㎡ 미만이므로 기준면적 12,500 ㎡입니다. 30,000 ÷ 12,500 = 2.4 → 올림 3 × 20 = <b>60 ㎥</b>, 채수구 <b>2개</b>입니다.</details>
